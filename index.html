Bucle FOR

toca para girar▸ toca

Recorre cada elemento de una lista, uno por vuelta.

for elemento in lista: print(elemento)

Contador + FOR

toca para girar▸ toca

Un contador numera los elementos mientras los recorres.

contador = 1 for elem in lista: print(contador, elem) contador += 1

Indexación

toca para girar▸ toca

Cada elemento tiene una posición. La primera es 0.

lista[0] # primero lista[1] # segundo lista[2] # tercero

input()

toca para girar▸ toca

Lee lo que escribe la persona. Para usarlo como número, conviértelo con int().

texto = input("¿Qué eliges? ") numero = int(input("Número: "))

IF / ELSE

toca para girar▸ toca

Si la condición es True corre un bloque; si no, el otro.

if condicion: # si True else: # si False

f-strings

toca para girar▸ toca

Meten variables dentro de un texto. La f va antes de las comillas.

nombre = "Ana" print(f"Hola, {nombre}")

Booleana en if

toca para girar▸ toca

Una variable True/False ya sirve como condición.
